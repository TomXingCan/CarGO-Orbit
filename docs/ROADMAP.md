# Roadmap

Milestones express direction, not release dates. A feature requiring an unavailable public integration contract stays unsupported until that contract exists.

| Version | Milestone | Acceptance focus |
| --- | --- | --- |
| `0.0.1-dev` | Bootstrap + EUI Adapter | Lightweight core, safe saved settings, public skinning boundary, diagnostics, test panel, and feature stubs. Retail validation remains required. |
| `0.1.0` | InfoBar foundation | Independently implemented bar, layout, and module lifecycle with documented public styling. |
| `0.2.0` | Enhanced Resource Bars host/overlay POC | Proceed only with a documented, stable host contract and safe public game data. |
| `0.3.x` | First validated resource predictions | Validate individual predictions against game behavior and restricted-value rules. |
| `0.5.0` | Personal daily-use milestone | Stable lifecycle, useful defaults, and practical everyday reliability. |
| `1.0.0` | Possible public release | Review compatibility, ownership, documentation, and release readiness. |

The next implementation step is **InfoBar foundation**. The current bootstrap does not add information modules, resource prediction, overlays, class tools, native options integration, extra locales, import/export, or packaging automation.

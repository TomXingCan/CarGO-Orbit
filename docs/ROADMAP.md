# Roadmap

Milestones express direction, not release dates. Features requiring unavailable public integration contracts remain unsupported until those contracts exist.

| Version | Milestone | Acceptance focus |
| --- | --- | --- |
| `0.0.1-dev` | Bootstrap + EUI Adapter | Lightweight core, safe settings, public styling boundary, diagnostics, and test panel. |
| `0.1.0` | InfoBar foundation + Time provider | Implemented locally: nine stable slots, independent center geometry, provider lifecycle, clock settings, visibility, and commands. Retail validation remains pending. |
| `0.1.x` | InfoBar core providers | System / Currency / Durability / Spec / Travel / XPRep / MicroMenu on the existing registry and owned hosts. |
| `0.2.0` | Enhanced Resource Bars host/overlay POC | Require a documented stable host contract and safe public game data. |
| `0.3.x` | First validated resource predictions | Validate predictions against game behavior and restricted-value rules. |
| `0.5.0` | Personal daily-use milestone | Stable lifecycle, useful defaults, and everyday reliability. |
| `1.0.0` | Possible public release | Review compatibility, ownership, documentation, and release readiness. |

The next implementation milestone is **0.1.x InfoBar core providers**, after the foundation's Retail acceptance checks. Only Time is implemented in `0.1.0`. Enhanced Resource Bars retains its existing later milestone.

This release does not add other providers, LDB, secure flyouts, resource prediction, native options registration, a drag-and-drop editor, import/export, or private host integrations.
